# GOAT Arena 2.2 현재 구현 및 출시 준비 보고서

- 기준일: 2026-10-11 (KST)
- 상태: 최신 제품 결정을 로컬 코드와 자동 검증에 반영했다. 프로덕션에는 배포하지 않았다.
- 경쟁전: `ARENA_COMPETITIVE_ENABLED=false`가 기본값이며 추후 별도로 활성화한다.

## 점수와 내부 MMR

- 일반전은 공개 순위가 없는 숨은 MMR을 사용한다. 시작값은 1000이다.
- 경쟁전은 내부 Glicko-2 MMR과 공개 경쟁전 점수를 별도로 저장한다.
- 내부 MMR은 상대 선택과 경기 결과에 따른 공개 점수 증감 폭 계산에만 사용한다.
- 공개 경쟁전 점수는 승패와 양쪽 내부 MMR의 기대 승률로 증감한다.
- 티어와 전체·학교·대학·N수생·직장인 순위는 모두 공개 경쟁전 점수만 사용한다.
- 주간 모의고사는 응시한 배치 완료 사용자의 경쟁전 내부 MMR·RD·변동성만 바꾼다. 공개 경쟁전 점수와 티어는 바꾸지 않으며 미응시자는 아무 값도 바뀌지 않는다.
- 경기별 및 주차별 고유 정산 원장을 사용해 동일 결과의 중복 반영을 차단한다.

## 레이팅 정책

- Glicko-2 기본 후보값은 Rating 1500, RD 350, Volatility 0.06, Tau 0.5다.
- 배치 표본 수에 따른 초기 RD는 `350 / sqrt(유효 표본 수)`다.
- 배치 1~5회 초기 Volatility 후보는 0.10, 0.09, 0.08, 0.07, 0.06이다.
- 적은 배치 표본은 큰 RD를 유지하므로 초기 경쟁전 결과에 더 크게 움직인다.
- 이후 RD와 변동성은 Glicko-2로 매 경기 연속 수렴한다. 5번째와 6번째 경기 사이에 인위적인 단계 전환은 없다.
- 연패 뒤 첫 승리와 연승 뒤 첫 패배는 직전 연속 결과 길이에 따라 변화 폭을 완화한다.
- 레이팅과 공개 점수 상수는 모두 환경설정 가능한 초기 운영 가설이다.

## 일반전

- 현재 숨은 MMR과 가까운 승인된 실제 사용자 기록 또는 운영 기준 기록을 선택한다.
- 서로 비슷한 난도의 서로 다른 5문항을 받을 수 있으며 문항당 제한 시간은 10분이다.
- 정오답, 문항 난도와 유효 풀이 시간을 반영한 내부 성취지표로 승패를 정한다.
- 데스크톱은 파일 업로드, 태블릿·휴대폰은 문항별 격자 풀이판으로 풀이과정을 필수 제출한다.
- 결과는 숨은 MMR과 기존 XP에 반영되며 공개 경쟁전 점수에는 영향을 주지 않는다.
- 사용자가 본 문항은 일반전과 경쟁전을 합친 다음 5경기 동안 같은 사용자에게 다시 배정하지 않는다.
- 승인된 과거 기록 자체는 다른 적격 사용자에게 즉시 다시 사용할 수 있다.
- 풀이 이상 신호를 자동 검사하되 사용자에게 패널티·정산 지연·이메일을 주지 않는다.
- 신호가 없는 완료 기록은 자동으로 상대 기록 풀에 들어간다.
- 신호가 있는 기록은 `REVIEW_REQUIRED`로 운영자 검토 대기하며, 승인 시 `AVAILABLE`, 거부 시 `INVALID`가 된다.
- 일반전 전용 순위표는 없다.

## 경쟁전

- 일반전 3경기와 별도의 1~5회 배치 확정 조건을 유지한다.
- 현재 내부 MMR과 가까운 승인된 경쟁전 과거 기록을 선택한다.
- 사용자가 본 문항은 다음 5경기 동안 다시 배정하지 않는다.
- 승패는 일반전과 같은 난도 보정 성취지표를 사용한다.
- 확정 경기마다 현재 도전자의 내부 MMR과 공개 경쟁전 점수만 한 번 갱신한다.
- 과거 상대 기록 소유자의 현재 MMR·공개 점수·XP·전적은 변경하지 않는다.
- 경쟁전은 기존 무결성 보류와 운영자 판정 흐름을 유지한다.
- 풀이 업로드가 끝난 뒤에는 자발적 포기를 허용하지 않는다.

## 친선전과 단체 도전장

- 회원 친선전 난도는 양쪽의 경쟁전 내부 MMR, 일반전 숨은 MMR, 기본값 1000 순으로 구한 유효 MMR 평균을 사용한다.
- 친선전과 단체 도전장은 MMR·공개 경쟁전 점수·티어·XP를 바꾸지 않으며 자동 부정행위 검사를 하지 않는다.
- 로그인 회원은 완료한 경기의 같은 5문항을 공유하는 단체 도전장 링크를 만들 수 있다.
- 링크는 생성 후 3일 동안 여러 게스트가 로그인 없이 참여할 수 있다.
- 같은 닉네임·생년월일 조합은 도전장마다 한 번만 풀고, 같은 조합으로 재접속하면 진행 중 시도 또는 완료 순위표를 연다.
- 순위는 정답 수 내림차순, 동점이면 유효 풀이 시간 오름차순이며 완전 동률은 공동 순위다.
- 발신자 결과는 현재 참가한 사용자가 모두 완료한 순간 공개한다. 한 번 공개된 뒤 새 참가자가 들어와도 다시 숨기지 않는다.
- 참가자 상세 화면은 실제 문제, 제출 답안, 정오답, 기준 정답률, 풀이 시간, 풀이과정과 난도 보정 성취지표를 표시한다.

## 운영자 화면

- 최근 30일 단방향 경쟁전 MMR 정산 수, 평균·누적·절대 변화, 정산 전후 평균, 승패별 내부 MMR 및 공개 점수 변화를 표시한다.
- 설정된 평균 드리프트 경고 기준을 넘으면 `검토 필요`로 표시한다.
- 일반전 풀이 이상 신호 기록의 문제·신호·상태를 확인하고 승인 또는 제외할 수 있다.
- 경쟁전 배치, 내부 MMR, 공개 경쟁전 점수와 경기당 정산 원장을 조회할 수 있다.
- 페이백 및 구형 Arena 경제·Standing 운영 기능은 활성 운영 화면과 런타임에서 사용하지 않는다.

## 데이터와 인덱스

- 경쟁전 프로필은 내부 MMR과 공개 경쟁전 점수를 함께 저장하되 역할을 분리한다.
- 일반전·경쟁전 기록은 `AVAILABLE`, `RESERVED`, `REVIEW_REQUIRED`, `INVALID` 상태를 사용한다.
- 문항 재노출 제한은 최근 경기의 문제 인스턴스 해시로 계산한다.
- 주간 모의고사 내부 MMR은 사용자·주차 고유 정산 원장으로 관리한다.
- 인덱스 준비 도구는 staging 명시와 apply 플래그가 함께 있을 때만 외부 DB를 변경한다.

## 현재 비활성 릴리스의 프로덕션 차단 항목

1. staging DB에 필요한 인덱스를 실제 적용하고 대조하지 않았다.
2. 실제 staging 트랜잭션, 동시 예약·정산과 검토 승인 경쟁 상태를 검증하지 않았다.
3. 실제 Cloudinary/R2 환경에서 데스크톱 업로드, 모바일 격자 승격, 서명 열람과 삭제를 검증하지 않았다.
4. 실제 데스크톱 브라우저, iPad와 휴대폰의 전체 경기 QA를 완료하지 않았다.
5. 실사용 일반전 문제 데이터와 기록 풀의 난도·정답 검수를 완료하지 않았다.
6. 공개 도전장의 참가자 수·저장량 상한과 대규모 순위 페이지네이션은 아직 운영 한도가 없다.
7. 가입하지 않은 게스트의 보존 기한 종료와 외부 풀이 파일 삭제 재시도를 staging에서 검증해야 한다.
8. 네이티브 Pro 판매도 함께 열 경우 Apple 상품 식별자와 Sandbox 구매·복원·갱신·환불 검증이 필요하다.

기존 사용자·재무·진행 중 구형 경기는 0건이라는 제품 전제를 적용하므로 별도 이관·정산 작업은 현재 차단 항목에 포함하지 않는다.

## 향후 경쟁전 활성화 조건

경쟁전 활성화는 사용자가 추후 진행한다. 그 전에 다음이 필요하다.

1. MMR 구간별 승인된 실제 경기 기록과 실제 문항·정답률·풀이·레이팅 스냅샷 확보
2. 실제 사용자 분포에서 단방향 MMR 드리프트와 공개 점수 분포 관찰
3. 운영자 30일 지표의 경고 기준과 베타 중단 기준 확정
4. 문제·기록 부족, 예약 충돌과 무결성 검토 적체에 대한 staging 부하 검증

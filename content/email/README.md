# Matths 이메일 문구 편집 위치

이 디렉터리의 파일은 발송되는 이메일과 함께 전송되는 우편함 문구를
기능별로 모아둔 곳입니다. 문구만 바꿀 때는 서비스 로직 대신 아래
파일을 수정합니다.

- `auth.js`: 비밀번호 재설정 인증코드·링크
- `support.js`: 문의 접수 알림·문의 답변
- `account.js`: 계정 활성·비활성·정지·탈퇴, 역할 및 경고 변경
- `community.js`: 게시글·댓글 경고
- `nickname.js`: 닉네임 강제 변경 요청
- `moderation.js`: 운영 안내 이메일의 공통 인사말과 맺음말
- `privateMock.js`: 사설 모의고사 업로드 알림, 소명 요청·검토 결과,
  이용 제한 기간, 정답 정정, 문제 이의신청 결과

관리자가 직접 입력한 이메일 본문은 입력한 내용을 그대로 사용하며,
공통 HTML 레이아웃과 발신자 설정은 `services/emailService.js`가
담당합니다.

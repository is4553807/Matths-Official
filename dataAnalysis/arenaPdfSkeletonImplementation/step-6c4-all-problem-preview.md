# PDF 스켈레톤 구현 6-C-4 - 전체 200문항 통합 미리보기

- 통합 미리보기: `all-problem-preview.html`
- 구현 스켈레톤: 200개
- 텍스트·수식형: 185개
- 그래프·도형형: 15개
- 실제 시각자료 렌더: 15/15
- MathJax 수식 노드: 1,220개
- 수식 노드가 없는 카드: 0개
- 남은 원시 TeX: 0개
- 브라우저 경고·오류: 0건
- 운영 출제 풀 연결: `false`

전체 구현 배치를 한 화면에 모아 연도·문항·제목·구조 ID 검색, 구현 배치 필터, 그래프·도형형 필터, 해설 전체 펼치기를 제공한다. Wave 3의 15개 문항은 PDF 원문 수치 고정 fixture를 사용하고, 나머지 문항은 source ID별 고정 seed 생성 샘플을 사용한다.

통합 렌더 검수 중 Wave 1·2 텍스트 생성기의 단일 역슬래시가 JavaScript 문자열에서 소실되어 `sum`, `frac`, `pi`, `to` 등이 평문으로 남는 문제를 발견했다. 관련 8개 생성기 파일의 prompt·solution TeX 이스케이프를 복구하고 전체 200개를 문항별 200 seed, 총 40,000회 이중 검산했다.

이 산출물은 구현 내용 감사용이며 GOAT Arena 1대1 운영 출제에는 아직 연결하지 않았다.

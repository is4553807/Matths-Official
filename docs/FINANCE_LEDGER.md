# 관리자 자금 장부

관리자 자금 현황은 결제 승인 원장, 이용 주기별 페이백 판정, 실제 페이백 지급
기록, 사업자 출금 기록을 매일 대조해 계산합니다.

## 출금가능액 원칙

1. 판정이 끝나지 않은 이용 주기는 가능한 최대 페이백 전액을 준비금으로 둡니다.
2. 페이백이 확정됐지만 아직 송금하지 않은 금액은 별도로 전액 보관합니다.
3. PG 수수료 준비금과 기타 미지급 비용을 제외합니다. 세금 준비금은 이 장부의
   출금가능액 계산에 포함하지 않습니다.
4. 출금가능액은 실제 현금 잔액과 확정이익 잔액 중 작은 값을 넘을 수 없습니다.
5. 서버는 관리자 입력액이 출금가능액을 1원이라도 넘으면 저장하지 않습니다.

`FINANCE_PG_FEE_RESERVE_BPS`는 PG 계약서의 부가세 포함 최종 수수료율을
1%당 100bp로 입력합니다. 예를 들어 최종 수수료율이 3.3%라면 `330`입니다.
계약상 결제수단별 수수료율이 다르면 실제 결제 구성에서 발생할 수 있는 최대
수수료를 충당할 수 있도록 운영 비율을 정합니다. 값이 없으면 사업자 출금
기능은 잠깁니다.

이 준비금은 PG 수수료만 계산합니다. 부가가치세·종합소득세·지방소득세 등
세무 신고와 납부 자금은 별도의 회계·세무 절차로 관리합니다.

페이백 자격과 금액은 일일 작업에서 자동 확정됩니다. 실제 계좌 송금은 은행 또는
지급대행 API가 연결되기 전까지 운영자가 송금한 뒤 페이백 정산 화면에서 완료로
기록해야 합니다. 송금하지 않은 건을 완료 처리하면 안 됩니다.

완료 버튼을 누른 시점에 지급 담당 운영자 ID·이름·이메일 스냅샷과 완료 시각을
보존하고, 사용자에게 Matths·GOAT Arena 공용 우편함 알림과 해당 운영자 계정에서
발신한 이메일을 전송합니다. 이메일만 실패한 경우 실제 송금 및 완료 기록은
되돌리지 않으며 같은 지급 이력에서 이메일만 재발송합니다. 완료·재발송을 포함한
관리자 요청은 운영 감사 로그에도 별도로 남습니다.

# Matths 현행 시스템

기준일: 2026-10-11 (KST)

## 제품 구성

Matths는 고등학교 수학 학습, 평가, 배치고사, 주간 모의고사, GOAT Arena, 커뮤니티, 자료실, 학부모·학원·운영자 기능을 제공한다. 웹 서버는 Express와 EJS로 구성되며 iOS/iPad 앱은 같은 MongoDB 데이터와 `/api/v1` JSON API를 사용한다.

## 계정과 플랜

- 계정 플랜은 무료와 Pro 두 가지다.
- Pro 기본 가격은 30일 5,500원이며 환경변수로 조정한다.
- 관리자는 기간 제한 없는 관리자 권한을 사용한다.
- 웹은 세션 쿠키, 앱은 Bearer 인증을 사용한다.
- 닉네임은 회원과 도전장 게스트가 하나의 정규화된 네임스페이스를 공유한다.

## 학습과 평가

- 개념 학습, 문제 풀이, 오답 복습, 일반 평가와 배치고사는 서버 정본 서비스에서 채점한다.
- 주간 모의고사에 참여한 사용자만 그 결과로 경쟁전 내부 MMR이 변한다.
- 주간 모의고사는 공개 경쟁전 점수를 바꾸지 않으며, 미응시는 어떤 변화도 없다.

## GOAT Arena

- 일반전은 숨은 MMR을 사용해 난도와 상대 기록을 정한다.
- 경쟁전은 일반전 3경기와 1~5회 배치 결과를 사용한다. 내부 Glicko-2 MMR은 매칭과 점수 증감 계산에, 공개 경쟁전 점수는 티어와 모든 랭킹에 사용한다.
- 친선전은 두 회원의 유효 MMR 평균으로 문제 난도를 정한다.
- 도전장은 완료한 Arena 문제를 3일 동안 여러 게스트에게 공유하고 순위를 만든다.
- 모든 모드는 5문항, 문항당 10분이며 답안과 풀이과정을 저장한다.

## 데이터와 운영

MongoDB가 계정·경기·평가·결제·운영 상태의 정본이다. 풀이 이미지와 대용량 파일은 설정된 파일 저장소에 두고 MongoDB에는 접근 제어와 무결성 확인에 필요한 메타데이터를 저장한다. 정산과 결제 변경은 멱등키와 트랜잭션 경계를 사용한다.

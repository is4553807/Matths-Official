# GOAT Arena 공통 경기 규칙

## 경기 단위

- 한 경기는 5문항이다.
- 각 문항 제한 시간은 10분이며 다음 문항으로 이동하면 답안과 풀이과정이 확정된다.
- 컴퓨터는 파일 업로드, 태블릿과 휴대폰은 문제 아래 격자 풀이판을 사용한다.
- 풀이 촬영·업로드 시간은 유효 풀이 시간에 포함하지 않는다.
- 최종 제출 뒤에는 자발적으로 경기를 포기할 수 없다.

## 문제와 결과

- 일반전과 경쟁전의 두 참가자는 서로 다른 문제 세트를 받을 수 있다.
- 서버는 실제 문항, 정답, 문항 정답률, 풀이 시간과 풀이과정을 경기 스냅샷에 고정한다.
- 결과 화면은 양쪽의 5문항, 제출 답안, 정오답, 총 정답 수, 유효 풀이 시간, 내부 성취 점수와 전체 풀이과정을 보여준다.
- 별도의 공식 답안지나 모범 풀이 페이지는 제공하지 않는다.

## 승패와 정산

- 일반전과 경쟁전은 정오답, 문항 난도와 유효 풀이 시간을 반영한 내부 성취 점수를 비교한다.
- 점수 차이가 설정된 근소 범위 안일 때만 유효 풀이 시간을 보조 기준으로 사용한다.
- 결과가 유효하게 확정될 때 경기 정산은 한 번만 실행된다.
- 일반전은 숨은 MMR만 갱신한다. 경쟁전은 내부 MMR을 갱신한 뒤 그 기대 승률에 따라 공개 경쟁전 점수를 증감한다.
- 친선전과 도전장은 어떤 MMR도 바꾸지 않는다.

## 공정성

- 경쟁전은 기존 부정행위 감지와 운영 검토를 적용한다.
- 일반전은 자동 감지를 실행하지만 사용자 패널티나 결과 대기 없이 경기 결과를 확정한다. 신호가 있는 기록만 운영자 승인 전까지 상대 기록 풀에서 제외한다.
- 회원 친선전과 게스트 도전장은 자동 부정행위 검사를 적용하지 않는다.
- 모든 결과·풀이 파일 조회는 경기 참가자, 도전장 권한 또는 운영자 권한을 확인한다.
- Arena는 요일 제한 없이 이용할 수 있다.

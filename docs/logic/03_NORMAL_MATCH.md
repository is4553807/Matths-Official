# GOAT Arena 일반전

## 참가와 난도

일반전은 로그인한 학생 계정이 무료로 이용한다. 최초 숨은 MMR은 1000이며 공개 순위표나 일반전 티어는 없다. 서버는 숨은 MMR을 U1~U9 난도로 변환하고 현재 실력에 가까운 유효 기록을 찾는다.

## 상대 기록 선택

- 상대는 운영자가 지정한 고정 세트가 아니라, 유효하게 완료된 실제 일반전 기록이다.
- 상대 기록의 당시 숨은 MMR과 현재 사용자의 숨은 MMR 차이가 작은 기록을 우선한다.
- 상대 풀이·결과 화면에서 본 문제도 제외 대상이다. 과거 기록 소유자가 본 상대 문제와 늦게 다시 연 결과도 노출 시점부터 포함한다. 시작 전에 취소한 매칭은 10경기 창을 앞당기지 않는다.
- 사용자가 본 문항은 그 사용자의 다음 10경기 동안 다시 배정하지 않는다. 상대 기록 자체는 다른 문항 조합에 사용할 수 있다.
- 사용할 실제 기록이 없는 초기 구간에서는 검증된 기준 문제 기록을 사용한다.
- 사용자와 상대는 서로 다른 5문항을 풀 수 있다.

## 진행과 결과

답안과 5문항의 풀이과정 제출이 필수다. 제출 요건이 충족되면 정오답, 문항 난도와 유효 풀이 시간을 반영해 결과를 즉시 확정한다. 자동 감지 신호가 있어도 사용자 패널티나 대기, 이메일을 만들지 않는다. 감지되지 않은 기록은 바로 상대 기록 풀에 들어가고, 감지된 기록은 운영자가 문제없음으로 승인한 뒤 풀에 들어간다. 결과에는 내 답안과 양쪽 풀이과정이 포함된다.

## 숨은 MMR

승·패·무 결과마다 현재 사용자의 숨은 레이팅, RD와 변동성을 Glicko-2 방식으로 다시 계산한다. 연승 뒤 패배나 연패 뒤 승리처럼 기존 흐름이 뒤집힐 때는 설정된 완충 배율을 적용한다. 상대 기록 소유자의 현재 값은 바꾸지 않는다.

## 다른 기능과 연결

- 유효한 일반전 완료는 기존 XP 규칙을 따른다.
- 유효한 일반전 3경기는 경쟁전 배치고사 해금 조건에 포함된다.
- 결과 화면에서 현재 경기의 문제를 사용하는 단체 도전장 링크를 만들 수 있다.

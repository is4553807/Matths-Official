# GOAT Arena 경쟁전

## 참가 조건과 배치

- 유효한 일반전 3경기를 완료해야 배치고사에 참여할 수 있다.
- 배치고사는 최소 1회, 최대 5회까지 완료한 뒤 사용자가 결과를 확정한다.
- 서버 오류는 시도 횟수를 소비하지 않는다.
- 사용자 중단은 시도 횟수를 자동 복원하지 않는다.
- 5회를 모두 소진하고 유효 결과가 없으면 운영자 승인 초기화가 필요하다.

## 내부 MMR과 초기 경쟁전 점수

기본 내부 MMR은 1500, RD는 `350 / sqrt(유효 배치 표본 수)`이며 변동성은 1~5회 순서로 0.10, 0.09, 0.08, 0.07, 0.06을 사용한다. 배치 확정 시 공개 경쟁전 점수를 초기화하고 기존 티어 컷오프를 공개 점수에 적용한다. 모든 값은 설정 가능한 운영 가설이다.

## 경기 배정

현재 내부 MMR과 가까운 사용자의 유효 경쟁전 기록을 선택한다. 경기에는 상대 기록의 당시 MMR·RD·변동성, 문제, 정답률, 정오답, 유효 풀이 시간과 풀이과정을 고정한다. 두 참가자는 비슷한 난도의 서로 다른 문제 세트를 받을 수 있다. 사용자가 본 문항은 다음 10경기에 다시 배정하지 않는다.

## 내부 MMR과 공개 점수 정산

- 결과 확정 시 현재 도전자만 한 번 갱신한다.
- 상대 기록 소유자의 현재 MMR·공개 점수·전적·XP는 바꾸지 않는다.
- 매 경기 후 승패로 내부 MMR, RD와 변동성을 다시 계산한다.
- RD 수렴으로 변동 폭을 연속적으로 안정시키며 5번째와 6번째 경기 사이의 인위적인 경계는 두지 않는다.
- 경기 결과와 양쪽 내부 MMR의 기대 승률을 사용해 공개 경쟁전 점수 증감 폭을 정한다.
- 연승·연패 반전 결과에는 설정된 완충 배율을 적용한다.

전체, 고등학교, 대학교, N수생과 직장인 랭킹은 모두 공개 경쟁전 점수만 사용한다.

## 운영 상태

경쟁전 실행 여부는 `ARENA_COMPETITIVE_ENABLED`로 제어한다. 활성화 전에는 레이팅 시뮬레이션, 스테이징 인덱스, 동시 정산, 실제 저장소, 브라우저와 모바일 QA를 통과해야 한다.

# 친선전과 단체 도전장

## 회원 친선전

- 친구 관계인 로그인 사용자끼리 초대하고 수락한다.
- 두 사용자의 경쟁전 내부 MMR을 우선 사용하고, 없으면 일반전 숨은 MMR을 사용한다.
- 두 값이 모두 없으면 해당 사용자는 1000으로 계산한다.
- 문제 난도는 두 참가자 유효 MMR의 평균으로 정한다.
- 결과는 MMR, 티어와 XP를 바꾸지 않으며 자동 부정행위 검사를 하지 않는다.

## 단체 도전장 생성

로그인 사용자는 완료한 일반전 또는 경쟁전 결과에서 도전장을 만든다. 링크는 생성 시점부터 3일 동안 새 참가를 받으며 인원 제한이 없다. 모든 참가자는 생성자가 풀었던 같은 5문항을 푼다.

발신자 점수와 풀이과정은 현재 참가자가 모두 완료한 순간 공개한다. 공개 이후 새 참가자가 들어와도 다시 숨기지 않는다.

## 게스트 참가

- 로그인이나 회원가입 없이 닉네임과 생년월일을 입력한다.
- 닉네임 사용 가능 여부는 입력 중 서버가 자동 확인한다.
- 같은 링크에서 같은 닉네임과 생년월일 조합은 한 번만 풀 수 있다.
- 완료한 조합으로 다시 접속하면 새 시도 대신 순위표를 보여준다.
- 다른 닉네임과 생년월일은 별도 참가자로 처리한다.

## 순위와 공개

도전장 순위는 정답 수가 많은 순, 정답 수가 같으면 유효 풀이 시간이 짧은 순이다. 결과가 공개되면 참가자별 실제 문제, 제출 답안, 정오답, 풀이 시간, 난도 보정 점수와 풀이과정을 상세 탭에서 확인한다. 생성자의 점수는 결과 공개 조건이 충족될 때 함께 공개한다.

## 가입과 기록 연결

게스트는 순위 화면에서 역도전장을 제안할 수 있으며 먼저 회원가입한다. 가입 시 같은 닉네임과 생년월일, 브라우저 소유 증명, 최초 참가일 확인이 모두 맞아야 기존 도전장 기록을 계정에 연결한다.

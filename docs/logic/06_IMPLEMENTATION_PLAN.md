# 완료 정의

1. 학습권이 남으면 새 패키지를 구매할 수 없다.
2. 학습권 0 사용자는 Arena와 주간 시험에 접근할 수 없다.
3. Main 사용자는 학습권 만료 시 Sub로 강등된다.
4. Main 72시간 내 갱신은 시험 없이 변환된 Sub 랭크에서 재개한다.
5. 72시간 초과 갱신은 랭크 복귀전을 완료해야 한다.
6. 최고점이어도 정상 변환 기준보다 높은 배치를 받지 않는다.
7. 20:00 cutoff가 서버 시각으로 정확히 적용된다.
8. 새 결제주기의 페이백 심사가 독립적으로 작동한다.
9. 일요일 공개 전환이 원자적이다.

Main Division 규정 화면은 캐시를 우회해 현재 활성 정책을 DB에서 직접 읽고 최대 공격 티어 차이, 차이별 최소 예치 일수, 상대 재매칭 제외 기간, 복수전 배수·수수료와 KST 적용일을 표시한다. 규정 본문의 티어 차이 설명과 GOAT Arena 메인 소개의 최대 티어 차이도 같은 정책 값을 사용한다. 내부 정책 버전 코드는 경기 생성·정산 스냅샷과 화면 뷰모델을 결속하는 데 사용하되, 사용자 화면에는 서비스 코드 대신 한국어 운영 기준명만 표시한다. 활성 정책이 없으면 임의 기본값을 보여주지 않고 신규 Main 경기가 중단되었다는 안전 차단 안내를 표시한다.

학습권 이용 종료 알림은 `AccessCycle.expiresAt`을 서버 권위 예정 종료 시각으로 사용한다. 이용 주기와 72·24·6시간 구간 조합을 유일 키로 저장하고, 사이트 우편함도 별도 멱등 키로 생성한다. 서버 중단으로 여러 구간을 한꺼번에 놓친 경우 가장 긴급한 구간 한 건만 보내고 이전 구간은 건너뜀으로 기록한다. 사이트 우편 저장은 이메일 사업자 장애와 분리하며, 이메일은 15분부터 지수 간격으로 최대 5회 재시도한다. 완료·재시도 대기 알림은 다음 처리 대상 조회에서 제외하여 이용자가 많아져도 뒤 사용자가 굶지 않게 한다.

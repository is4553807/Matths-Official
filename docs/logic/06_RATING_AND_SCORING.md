# Arena 내부 MMR, 공개 경쟁전 점수와 경기 평가

## 내부 성취 점수

각 문항은 서버 정오답 값과 0~1 사이의 원본 정답률을 사용한다. 5문항의 실제 정답 수, 기대 정답 수와 분산으로 난도 보정 성취 점수를 계산한다. 정답률이 없거나 극단값이거나 5문항이 완전하지 않으면 공식 비교를 만들지 않는다.

일반전과 경쟁전은 두 성취 점수의 차이가 설정된 근소 범위를 넘으면 높은 쪽이 승리한다. 차이가 근소할 때는 유효 풀이 시간이 짧은 쪽이 승리하며 시간까지 같으면 무승부다. 도전장 순위는 정답 수와 시간을 사용하고 난도 보정 점수는 결과 정보로 함께 저장한다.

## Glicko-2 설정

- 기본 레이팅: 1500
- 기본 RD: 350
- 기본 변동성: 0.06
- 시스템 상수 Tau: 0.5
- 일반전 숨은 MMR 시작값: 1000

설정은 `services/goatArenaV2Config.js`에서 환경변수와 기본값을 검증한다. 잘못된 범위는 시작 시 오류로 처리한다.

## 적응형 변동

- 배치 표본이 적을수록 RD와 변동성이 크다.
- 내부 MMR의 RD와 변동성은 경기마다 연속적으로 수렴하며 특정 경기 수에서 갑자기 안정화 배율을 바꾸지 않는다.
- 공개 경쟁전 점수는 승패와 내부 MMR 기대 승률로 증감 폭을 계산한다.
- 주간 모의고사는 내부 MMR만 갱신하며 공개 경쟁전 점수에는 직접 영향을 주지 않는다.
- 연속 결과가 반전될 때는 이전 연속 길이에 따라 변화량을 완충한다.
- 승·패·무 정산 뒤 RD와 변동성도 결과와 함께 저장한다.

## 검증

`arena-v2:simulate`와 `arena-normal-baseline:simulate`는 일방 갱신에서 인플레이션·디플레이션, 실력 구간별 승률, 문제 세트 차이와 기준 기록 편향을 측정한다. 시뮬레이션 결과는 운영 상수 확정이 아니라 활성화 판단 자료다.

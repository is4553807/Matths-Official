# Arena 문항과 풀이 증거

## 문항 생성

Arena는 문제 골격과 유형 카탈로그를 이용해 실제 문항을 생성한다. 경기에는 생성된 문항 본문, 선택지·입력 형식, 서버 정답, 출처 정답률, 난도 코드와 생성 버전을 봉인한다. 그래프가 필요한 골격은 그래프 자산과 함께 렌더링한다.

## 난도 체계

- 일반전은 U1~U9를 사용한다.
- 경쟁전은 R1~R9를 사용한다.
- 대수, 미적분Ⅰ, 확률과 통계를 2·2·1 구성으로 배정한다.
- 일반전은 숨은 MMR, 경쟁전은 내부 MMR, 친선전은 참가자 평균 유효 MMR을 난도 입력으로 사용한다.
- 도전장은 생성 경기의 5문항을 그대로 사용한다.

## 풀이과정

웹 파일 업로드와 모바일 격자 풀이판은 같은 경기 증거 모델로 수렴한다. 모바일 판은 문항별 revision과 비교 후 저장 방식으로 중복·역순 쓰기를 막는다. 최종화된 5개 판은 원본 풀이 증거로 승격한다.

## 파일 권한

- 경기 참가자는 자신의 경기 결과가 공개된 뒤 양쪽 풀이를 볼 수 있다.
- 도전장 참가자는 결과 공개 조건 뒤 해당 도전장의 상세 풀이를 볼 수 있다.
- 운영자는 검토 권한이 있는 경기만 조회한다.
- 파일 요청은 DB 소유권과 경기 상태를 확인한 뒤 저장소 URL 또는 스트림을 반환한다.

## 무결성

서버는 파일 수, 총 용량, MIME과 이미지 시그니처를 검사하고 해시·저장 메타데이터를 기록한다. 일반전과 경쟁전 증거는 자동 이상 신호 탐지를 거친다. 일반전 신호는 사용자 제재 없이 기록 풀 승인만 보류하고, 경쟁전 신호는 기존 운영 검토 절차를 따른다. 친선전과 도전장은 자동 탐지하지 않는다.

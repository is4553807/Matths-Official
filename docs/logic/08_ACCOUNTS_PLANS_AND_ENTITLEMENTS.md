# 계정 플랜과 이용 권한

## 플랜

`FREE`와 `PRO`가 학생 계정의 현재 플랜 코드다. 무료 플랜은 만료가 없고 가격이 0원이다. Pro는 기본 30일, 5,500원이며 `MATTHS_PRO_PRICE_KRW`와 `MATTHS_PRO_BILLING_PERIOD_DAYS`로 설정한다. 관리자는 `SUPER_ADMIN` 권한으로 만료 없이 이용한다.

## 결제

- 웹 Pro 결제는 KG Inicis 주문·승인 흐름을 사용한다.
- 앱 Pro 결제는 설정된 Apple 상품 ID, 영수증 검증, 거래 소유권과 서버 알림을 사용한다.
- 결제 완료는 공급자 검증과 멱등 처리가 끝난 뒤에만 플랜에 반영한다.
- 환불은 결제 원장과 구독 상태를 함께 확인하고 운영 감사 기록을 남긴다.

## 권한 판정

`accountPlanService`가 역할, 시작일, 종료일과 상태를 읽어 무료·Pro·관리자 보기를 만든다. 기능 서비스는 표시 문자열이 아니라 이 권한 보기를 사용한다. 만료된 Pro는 자동으로 무료 보기로 해석된다.

## 가입과 닉네임

이메일, Google, Kakao와 Apple 인증이 지원된다. 회원 닉네임과 게스트 닉네임은 정규화된 공용 네임스페이스에서 원자적으로 예약한다. 게스트 기록 연결은 닉네임만으로 실행하지 않고 생년월일 해시, 브라우저 소유 증명과 사용자 확인을 요구한다.

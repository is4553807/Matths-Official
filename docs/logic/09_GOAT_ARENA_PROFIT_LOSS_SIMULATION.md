# 1. 이번 모델에서 제거한 이전 가정

이전 손익 모델에 있던 다음 항목을 모두 제거했다.

- 무료 Sub Arena
- 무료 방어자
- 무료 주 1회 공격
- 만료 사용자의 주간 모의고사
- 만료 사용자의 활성 Final Ranking
- 무료 사용자 유지율과 무료→유료 복귀율

현재 모델:

```text
학습권 0
→ Main 사용자는 Sub로 강등
→ GOAT Arena·주간 모의고사·Final Ranking 이용 정지
→ 결제창
```

```text
72시간 이내 재구독
→ Main-to-Sub Rank Convert
→ 랭크 복귀전 없음

72시간 초과 재구독
→ 재구독 랭크 결정전
→ 정상 변환 기준보다 낮은 Sub 배치
```

# 9. 이전 무료 Arena 모델과 비교

```text
무료 방어자 0명: 약 6.75%
무료 방어자 500명: 약 4.76%
무료 방어자 1,000명: 약 3.52%
```

새 모델:

```text
무료 방어자 없음
+ 학습권 0 즉시 이용 정지
+ 실제 활동 가능기간 감소
```

이유:

- 실제 학습권이 평균 26.4일차에 소진
- 만료 뒤 공격·방어·주간 모의고사 불가
- 방어로 점수를 회복할 시간이 줄어듦
- 적극 공격형은 배팅 소각 때문에 페이백에 불리함

# 10. 가장 중요한 사업 해석

## 10.1 페이백보다 재구독률이 중요

기준 시나리오에서 예상 페이백 지급률은 약 5%다.

손익을 크게 움직이는 값은:

1. Sub 만료자의 72시간 내 재구독률
2. Main → Sub 강등자의 72시간 내 재구독률
3. 주간 모의고사 접근 제한이 결제 전환에 주는 효과
4. 문제 제작·검수 원가
5. 신규 유저 획득비용

## 10.2 현재 페이백 난도는 높음

```text
페이백 수령자 약 9.81%
80% 페이백 약 1.5명 / 1,000명
100% 페이백 사실상 0명
```

마케팅에서 80%·100% 페이백을 크게 강조하면
실제 체감과 차이가 생길 수 있다.

## 10.3 학습권 만료 속도

30일 안에 학습권 0이 되는 사용자는 약
`85.25%`다.

따라서 결제창과 강등 안내는 일부 예외 사용자를 위한 화면이 아니라
대부분의 사용자가 경험하는 핵심 전환 화면이다.

# 11. 권장 운영 기준

## 11.1 강등 안내

공식 문구:

```text
학습권이 끝나면 Main에서 Sub로 강등됩니다.
```

같은 화면에 반드시 추가:

```text
Main 달성 기록은 보존됩니다.
72시간 내 재구독하면 직전 Main 성과를 반영한 Sub 랭크에서
랭크 복귀전 없이 시작할 수 있습니다.
```

## 11.2 재구독 KPI

베타에서 반드시 측정:

- Sub 24시간·72시간 내 재구독률
- Main 강등 24시간·72시간 내 재구독률
- 주간 모의고사 직전 만료자의 결제 전환율
- 랭크 복귀전 시작·완료·이탈률
- 20:00 전후 결제 전환율
- 만료 시점 Final Rank별 재구독률

## 11.3 재시뮬레이션 조건

다음 데이터가 각각 100건 이상 쌓이면 모델을 다시 보정한다.

- Sub 만료
- Main → Sub 강등
- 72시간 내 재구독
- 72시간 이후 재구독
- 페이백 심사
- 랭크 복귀전

# 12. 결론

현재 정책은 페이백 지급액보다
학습권 만료와 Main → Sub 강등을 통한 재구독 전환이 손익을 결정한다.

기준 시나리오:

```text
최초 결제자 1,000명
→ 연간 결제 약 1940건
→ 연매출 약 56,261,450원
→ 페이백·PG·고정비 후 약 51,015,403원
```

다만 신규 유입이 없는 폐쇄 코호트이므로
서비스 전체 매출 전망으로 사용하면 안 된다.

이 모델의 가장 큰 불확실성은
**Main → Sub 강등 후 72시간 내 재구독률**이다.

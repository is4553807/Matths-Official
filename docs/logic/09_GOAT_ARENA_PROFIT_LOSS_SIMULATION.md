# 1. 현재 시뮬레이션 범위

현재 모델은 유료 학습권 이용 주기와 만료 후 재구매 흐름만 계산한다.

```text
학습권 0
→ Main 사용자는 Sub로 강등
→ GOAT Arena·주간 모의고사·Final Ranking 이용 정지
→ 결제창
```

```text
72시간 이내 재구독
→ Main-to-Sub Rank Convert
→ 랭크 복귀전 없음

72시간 초과 재구독
→ 재구독 랭크 결정전
→ 정상 변환 기준보다 낮은 Sub 배치
```

# 2. 30일 결제주기 가정

## 2.1 사용자 유형

| 유형 | 비중 | 목표 일반 공격 | 30일 streak 성공확률 |
|---|---:|---:|---:|
| 최소 참여형 | 50% | 평균 2.5회 | 65% |
| 전략형 | 35% | 평균 7회 | 75% |
| 적극형 | 15% | 평균 14회 | 85% |

## 2.2 경기 가정

- 도전자 평균 승률: 40%
- Bronze 자기 학습권 반환 발생 비중: 도전자 승리의 20%
- 나머지 도전자 승리의 배팅 학습권은 소각
- 도전자 패배 시 유료 방어자에게 1일 이전
- 방어자는 정상 유료 이용 자격을 보유해야 함
- 일요일 Sub·Main 14:30 신규 경기 차단과 15:00~24:00 전체 잠금이 반영된 유효 공격량
- 실제 학습권이 0이 되면 추가 공격·방어·주간 시험 불가

## 2.3 결제시간

결제시간이 하루에 균등하게 분포한다고 가정했다.

```text
20:00 이전 결제 비중 ≈ 83.3%
20:00 이후 결제 비중 ≈ 16.7%
```

## 2.4 Main Division 재산출 대기

Main 정책은 `Sub 최종 페이백 점수 - 29 + 진입 보너스 2일`로 시작하고, Main 경기에서 양측 학습일수를 잠가 결과에 따라 이전한다. 하위 티어 초대 예약과 Main 전용 배수·수수료를 쓰는 복수전도 Main 체류 기간에 영향을 준다.

Main 복수전의 결과별 반환·이전·소각표는 확정되었다. 현재 시뮬레이션은 다음 실제 이용 행동값이 없어 아직 이 흐름을 계산하지 않는다.

- Main 티어 차이 1·2·3단계의 최소 배팅 1·2·3일과 최대 3단계는 확정값으로 입력
- 상향 공격·하위 초대·복수전 이용 빈도와 승률
- 초대 수락률·거절률·첫 수락까지 걸리는 시간
- Main 복수전 정상 승패·한쪽 No-show·양측 No-show 발생 비율

따라서 이 문서의 `Main 강등 발생`, `72시간 내 Main 재구독`, 연간 결제건수와 공헌이익은 아직 Main 운영 예측값으로 사용하지 않는다. 실제 이용 빈도 가정을 정하면 동일 코호트·정책 버전으로 다시 산출한다.

20:00 이후 결제자는 결제 당일 학습권을 차감하지 않는다.

# 9. 가장 중요한 사업 해석

## 9.1 페이백보다 재구독률이 중요

기준 시나리오에서 예상 페이백 지급률은 약 5%다.

손익을 크게 움직이는 값은:

1. Sub 만료자의 72시간 내 재구독률
2. Main → Sub 강등자의 72시간 내 재구독률
3. 주간 모의고사 접근 제한이 결제 전환에 주는 효과
4. 문제 제작·검수 원가
5. 신규 유저 획득비용

## 9.2 현재 페이백 난도는 높음

```text
페이백 수령자 약 9.81%
80% 페이백 약 1.5명 / 1,000명
100% 페이백 사실상 0명
```

마케팅에서 80%·100% 페이백을 크게 강조하면
실제 체감과 차이가 생길 수 있다.

## 9.3 학습권 만료 속도

30일 안에 학습권 0이 되는 사용자는 약
`85.25%`다.

따라서 결제창과 강등 안내는 일부 예외 사용자를 위한 화면이 아니라
대부분의 사용자가 경험하는 핵심 전환 화면이다.

# 10. 권장 운영 기준

## 10.1 강등 안내

공식 문구:

```text
사용 가능·초대 예약·경기 중 잠금 학습일수가 모두 0이고 미정산 경기가 없으면 Main에서 Sub로 강등됩니다.
```

같은 화면에 반드시 추가:

```text
Main 달성 기록은 보존됩니다.
72시간 내 재구독하면 직전 Main 성과를 반영한 Sub 랭크에서
랭크 복귀전 없이 시작할 수 있습니다.
```

## 10.2 재구독 KPI

베타에서 반드시 측정:

- Sub 24시간·72시간 내 재구독률
- Main 강등 24시간·72시간 내 재구독률
- 주간 모의고사 직전 만료자의 결제 전환율
- 랭크 복귀전 시작·완료·이탈률
- 20:00 전후 결제 전환율
- 만료 시점 Final Rank별 재구독률

## 10.3 Main v1.0 재산출 KPI

- Main 진입 시작 학습일수와 강등까지 평균 활동 일수
- 티어 차이별 상향 쟁탈전 성립률·승률·배팅 일수
- 하위 티어 초대 수락률·응답 시간·후보 재선정 횟수
- 초대 예약 취소·자동 해제 사유
- 사용자별 경기 학습일수 순이전 분포
- 복수전 권리 발생률·신청률·성립률·결과별 학습일수 이동량
- 반복 상대·연관 계정·학습일수 몰아주기 보류율
- 일요일 14시 30분 이후 신규 Main 경기 차단 건수와 15시 미정산 경기 보류 건수

## 10.4 재시뮬레이션 조건

다음 데이터가 각각 100건 이상 쌓이면 모델을 다시 보정한다.

- Sub 만료
- Main → Sub 강등
- 72시간 내 재구독
- 72시간 이후 재구독
- 페이백 심사
- 랭크 복귀전

# 11. 결론

현재 정책은 페이백 지급액보다
학습권 만료와 Main → Sub 강등을 통한 재구독 전환이 손익을 결정한다.

기준 시나리오:

```text
최초 결제자 1,000명
→ 연간 결제 약 1940건
→ 연매출 약 56,261,450원
→ 페이백·PG·고정비 후 약 51,015,403원
```

다만 신규 유입이 없는 폐쇄 코호트이므로
서비스 전체 매출 전망으로 사용하면 안 된다.

이 모델의 가장 큰 불확실성은 **Main 경기와 복수전의 학습일수 이전이 체류 기간을 얼마나 바꾸는지**와 **Main → Sub 강등 후 72시간 내 재구독률**이다. 결과별 정산표는 확정되었지만 실제 경기 이용·No-show·전환 데이터가 쌓이기 전까지 현재 수익 추정은 Sub 중심의 참고값으로만 사용한다.

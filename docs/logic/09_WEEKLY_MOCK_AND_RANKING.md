# 주간 모의고사와 경쟁전 랭킹

## 주간 모의고사와 내부 MMR

주간 모의고사를 응시한 배치 완료 사용자는 대표 결과에 따라 자신의 경쟁전 내부 MMR, RD와 변동성이 갱신된다. 공개 경쟁전 점수와 티어는 주간 모의고사로 바뀌지 않는다. 미응시자는 내부 MMR과 공개 점수 모두 변하지 않는다.

## 주간 모의고사

- 운영자가 시험지, 일정, 답안과 채점 기준을 관리한다.
- 웹과 앱은 같은 응시 시도와 제출 상태를 사용한다.
- 증거 업로드, 이의 제기와 운영 판정은 해당 시험 기록에 연결한다.
- 동일 사용자·주차의 내부 MMR 반영은 별도 정산 원장과 고유 인덱스로 한 번만 적용한다.
- 정답 정정으로 대표 결과가 바뀌면 기존 주차 정산과의 차이만 현재 내부 MMR에 보정한다.

## 랭킹 경계

- `ArenaCompetitiveProfile`의 내부 MMR은 매칭과 공개 점수 증감 계산에만 사용한다.
- 같은 프로필의 `competitiveScore`가 사용자에게 보이는 경쟁전 점수이며 기존 티어 컷오프도 이 점수에 적용한다.
- 일반전은 공개 순위표가 없다.
- 전체, 고등학교, 대학교, N수생과 직장인 랭킹은 모두 공개 경쟁전 점수로 계산한다.

## 표시와 개인정보

공개 랭킹은 서버가 만든 표시 이름과 허용된 학교·지역 정보만 사용한다. 이메일, 생년월일, 결제 정보와 파일 저장 키는 랭킹 응답에 포함하지 않는다.

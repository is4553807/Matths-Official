# 운영자 기능

## 계정과 플랜

운영자는 사용자 검색, 계정 상태, 무료·Pro 플랜, 만료일과 변경 이력을 확인한다. 플랜 변경은 사유, 수행자와 시간을 감사 로그에 남긴다.

## Arena 운영

- 진행 중 경기와 완료 경기 검색
- 일반전 기준 문제와 문항 카탈로그 검증
- 경쟁전 배치 프로필, 내부 MMR과 공개 경쟁전 점수 상태 조회
- 최근 30일 단방향 내부 MMR 순변화·평균 변화·절대 변동과 결과별 공개 점수 변화 확인
- 경쟁전 무결성 신호, 추가 소명과 운영 판정
- 일반전 감지 기록의 상대 기록 풀 승인 또는 무효 처리
- 배치 시도 초기화와 승인 이력
- 도전장과 게스트 기록의 권한 기반 조회

경쟁전 무결성 검토에서 이상 없음으로 확정하면 적용된 접근 제한을 해제하고 보류된 경기 정산을 계속한다. 일반전 감지 신호는 사용자 결과·XP·이용 권한에 영향을 주지 않으며, 운영자가 승인한 기록만 상대 기록 풀에 넣는다. 일반전 검토 결과 이메일은 발송하지 않는다.

## 학습·콘텐츠 운영

운영자는 문제 은행, 평가, 주간 모의고사, 자료실, 학원, 커뮤니티와 고객 문의를 각 전용 화면에서 관리한다. 파일이 포함된 작업은 업로드 검증과 저장소 상태를 함께 표시한다.

## 운영 지표

웹과 iPad 운영자 화면은 현재 원본 DB에서 조회한 같은 운영 지표를 사용한다. 무료·Pro 플랜, Pro 결제·환불, Arena 경기·기록 풀·배치·무결성, 단방향 레이팅 상태, 도전장과 주간 모의고사를 표시한다.

## 감사와 동시성

금전, 플랜, 제재, 경기 확정과 사용자 데이터 변경은 관리자 ID, 대상, 사유와 변경 결과를 기록한다. 같은 경기나 결제에 대한 중복 명령은 멱등키·고유 인덱스·트랜잭션으로 한 번만 적용한다.

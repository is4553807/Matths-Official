# GOAT Arena
# Rule Evaluation and Content Strategy

> 기준 정책: Sub v2.9 · Final Ranking v1.4  
> 목적: 사용자 이해도, 신뢰, 전환과 운영 난이도 평가

---

# 1. 종합 평가

현재 룰은 게임성과 수익화 구조가 강하다.

핵심 루프:

```text
결제
→ Sub 페이백 경쟁
→ Main 진입
→ 학습권 만료
→ 이용 제한
→ 재구독
→ Sub에서 새 페이백 경쟁
```

장점:

- 학습권의 가치가 명확함
- 주간 모의고사가 강한 재구독 동기
- 패키지 중복 구매 방지
- Main 성과가 72시간 내 갱신 혜택으로 연결
- 결제주기마다 새 페이백 기회
- 무료 무임승차와 유령 방어자 제거

위험:

- Main 사용자는 실제로 Sub로 강등되므로 강등의 체감이 강할 수 있음
- 페이백·랭킹·학습권·MMR이 동시에 존재해 설명 난이도가 높음
- 20:00와 72시간 경계에서 CS가 발생할 가능성
- 무료 방어자 제거로 매칭 유동성이 떨어질 수 있음
- 늦은 갱신 페널티가 과도하게 느껴질 수 있음

---

# 2. 학생 관점

## 긍정적

- 매주 모의고사를 볼 이유가 분명함
- Main 진입이 실제 성취로 느껴짐
- 72시간 내 갱신 시 시험을 피할 수 있음
- 결제할 때마다 다시 페이백에 도전 가능
- 랭킹 방어와 성장이라는 게임 목표가 명확함

## 부정적

- 학습권이 매일 줄고 경기에서도 변해 잔액 예측이 어려울 수 있음
- Main에서 Sub로 돌아가면 성취가 사라졌다고 느낄 수 있음
- 늦게 결제한 이유가 개인 사정이어도 페널티를 받는다고 느낄 수 있음
- 규칙을 읽지 않으면 20:00 cutoff를 놓칠 수 있음

## 학생에게 보여줄 핵심 문장

```text
학습권이 끝나면 Main에서 Sub로 강등됩니다.

72시간 내 재구독하면 시험 없이
직전 Main 성과를 반영한 Sub 랭크에서 다시 시작합니다.
Main 달성 기록은 프로필에 보존됩니다.
```

---

# 3. 학부모 관점

## 긍정적

- 중복 패키지 구매가 불가능함
- 사용기간과 결제주기가 분리되지 않음
- 주간 모의고사라는 교육적 사용 목적이 분명함
- 페이백 조건과 기록을 확인할 수 있음
- 자녀가 얼마나 참여했는지 데이터로 볼 수 있음

## 우려

- 학습권 예치가 사행성처럼 느껴질 수 있음
- 환급 조건이 복잡하면 광고와 실제 체감이 다르다고 느낄 수 있음
- 학습권 만료가 Main → Sub 강등으로 이어지는 이유를 납득하지 못할 수 있음
- 늦은 결제 페널티가 결제를 압박하는 장치처럼 보일 수 있음

## 학부모에게 보여줄 핵심 문장

```text
랭킹전은 학습 참여를 유도하는 선택형 기능입니다.

구매한 패키지는 중복 적립되지 않으며,
페이백 조건·심사일·현재 점수를 앱에서 투명하게 확인할 수 있습니다.
```

---

# 4. 운영자 관점

## 장점

- 구독 전환 이유가 강함
- 무료 이용자 서버 비용을 줄일 수 있음
- 학습권 총량과 결제주기를 통제하기 쉬움
- 결제주기마다 페이백 루프가 다시 시작됨
- Main 성과를 재구독 전환에 활용 가능

## 운영 위험

- 상태기계가 복잡함
- 72시간·20:00 경계 분쟁 가능
- Main-to-Sub 변환표에 대한 불만 가능
- 매칭 가능한 방어자 수가 줄어들 수 있음
- 결제·시험·랭킹 장애가 동시에 발생하면 보상 판단이 어려움
- 상세 규칙이 자주 바뀌면 신뢰가 떨어짐
- Main 상점의 방어 편의 기능이 경기 회피권이나 승리 구매로 오해될 수 있음
- `방어 일정 보호권`의 적용 시점과 공식 실적 제외 범위를 짧게 안내하지 않으면 경기 회피권으로 오해될 수 있음

## 운영 필수 장치

- 결제 전 요약 동의
- 만료 72·24·6시간 전 알림
- Main 만료 후 72시간 countdown
- 예상 변환 Sub 랭크 미리보기
- 20:00 cutoff 결제창 표시
- 모든 계산의 감사 로그
- 정책 버전과 적용일 공개
- 장애 보상 매뉴얼
- 상점 구매 전 가격·효과·만료·반환 불가 조건 요약 동의
- 방어 일정 보호권은 문제 열람 전 승패 없는 취소이며 공격자에게 1일이 이전된다는 명시

# 5. 룰 이해도 평가

현재 규칙을 한 화면에서 전부 설명하면 이해하기 어렵다.

사용자에게 필요한 규칙과 운영 계산을 분리해야 한다.

## 사용자에게 반드시 보여줄 6개 규칙

```text
1. 학습권이 끝나면 Main에서 Sub로 강등됩니다.
2. 학습권이 0이면 Arena와 주간 모의고사가 잠깁니다.
3. 학습권이 남아 있으면 새 패키지를 살 수 없습니다.
4. Main 강등 후 72시간 내 갱신하면 시험이 없습니다.
5. 72시간 이후에는 랭크 복귀전을 봅니다.
6. 20시 이후 결제는 다음 날부터 학습권이 차감됩니다.
```

## 기본 화면에서 숨길 수 있는 계산

- 백분위 공식
- MMR Soft Reset 공식
- Main-to-Sub 세부 환산표
- Final Rating 세부 가중치
- 멱등 키와 상태기계
- 페이백 이론 상한

이 내용은 상세 PDF와 FAQ에서 제공한다.

# 6. 설명 구조

## Level 1 — 한 줄 요약

```text
학습권으로 경쟁하고, 꾸준히 시험을 보며,
조건을 달성하면 페이백과 Main 진입에 도전하는 수학 랭킹 시스템
```

## Level 2 — 사용자 여정

```text
결제 → Sub → 페이백 → Main → 만료 → 재구독
```

## Level 3 — 상황별 설명

- 학습권이 0이 됐을 때
- Main에서 만료됐을 때
- 72시간을 넘겼을 때
- 주간 모의고사를 놓쳤을 때
- 새 시즌이 시작될 때

## Level 4 — 계산 상세

PDF·아카이브:

- Final Rating 공식
- MMR Soft Reset
- Main-to-Sub 환산
- 페이백 점수
- 동점 처리
- 사례 계산

# 7. 플랫폼별 콘텐츠 역할

## 앱·웹사이트

목적: 실제 행동 직전의 정확한 설명

필수:

- 결제창 cutoff 안내
- 만료 countdown
- 예상 랭크 변환
- 현재 페이백 점수
- 29일 이용 주기의 전일 학습 달성 현황과 하루 누락 시 해당 주기 조건 실패 안내
- 상황별 모달
- 상세 PDF 링크

## 아카이브 PDF

목적: 권위 원본과 신뢰

구성:

1. 2페이지 빠른 요약
2. 사용자 여정
3. 학습권·페이백
4. Sub·Main·Final Ranking
5. 결제 만료·72시간
6. 시험 종류
7. 계산 공식
8. 예시
9. FAQ
10. 정책 버전·변경 이력

PDF 첫 부분부터 복잡한 공식을 보여주지 않는다.

## Instagram Reels

목적: 발견과 감정적 관심

한 영상에 하나만 설명한다.

예:

- “수학 공부하고 페이백 받는 랭킹전”
- “Main 랭크는 어떻게 가나요?”
- “학습권이 0이 되면?”
- “72시간 안에 갱신해야 하는 이유”
- “주간 모의고사를 건너뛰면?”

권장 길이:

```text
15~35초
```

공식과 표는 넣지 않고 결과·혜택·긴장감을 보여준다.

## YouTube Shorts

목적: 검색 가능한 짧은 설명

Reels와 같은 원본 촬영을 사용할 수 있지만
제목·자막·도입을 질문형으로 바꾼다.

예:

- “GOAT Arena 학습권은 왜 매일 줄어드나요?”
- “Main 유저가 만료되면 어떻게 되나요?”
- “랭크 복귀전이란?”

영상 설명과 고정 댓글에서 관련 롱폼으로 연결한다.

## YouTube 롱폼

목적: 신뢰와 상세 이해

권장 시리즈:

1. 전체 시스템 7~10분
2. 학습권·페이백 5~8분
3. Sub와 Main 5~8분
4. Final Ranking·MMR 6~10분
5. 만료·재구독·랭크 복귀전 5~7분
6. 실제 계산 예시 8~12분

하나의 30분 영상보다 기능별 영상이 찾기 쉽다.

# 8. 같은 영상을 모든 플랫폼에 올리지 않는 방법

같은 촬영 원본을 사용하되 편집 목적을 다르게 한다.

```text
Master Recording
├─ Instagram Reels: 감정·혜택·화면 중심
├─ YouTube Shorts: 질문·검색어·정답 중심
└─ YouTube Long-form: 과정·예시·근거 중심
```

예: “Main 만료”

Instagram:

```text
Main 랭크, 학습권 0이면 사라질까?
→ 기록은 보존
→ 72시간 안에 갱신하면 시험 없음
```

YouTube Shorts:

```text
Main 유저가 72시간 안에 재구독하면 어떻게 배치될까?
→ Main-to-Sub 환산 설명
```

YouTube 롱폼:

```text
만료 시각
→ 결제창
→ 변환표
→ 늦은 갱신 상한
→ Final Ranking 기준점
```

# 10. 출시 전 권장 테스트

학생 5명과 학부모 5명에게 다음 질문을 한다.

```text
학습권이 0이면 무엇을 못 하나요?
Main에서 만료되면 어디서 다시 시작하나요?
72시간을 넘기면 어떤 시험을 보나요?
20시 이후 결제하면 언제 차감되나요?
페이백 조건은 무엇인가요?
```

각 질문의 정답률이 80% 미만이면
광고보다 앱 설명과 용어를 먼저 단순화한다.

# 11. 최종 권고

제품 내부 계산은 복잡해도 된다.

사용자가 기억해야 하는 규칙은 5개 이하로 유지해야 한다.

가장 중요한 표현은 사실을 직접 전달하는 것이다.

```text
학습권이 끝나면 Main에서 Sub로 강등됩니다.
```

이 문구를 공식 안내에서 사용한다.

단, 다음 문장을 함께 붙여 처벌만 강조되는 인상을 줄인다.

```text
Main 달성 기록은 보존됩니다.
72시간 내 재구독하면 직전 Main 성과를 반영한 Sub 랭크에서 시험 없이 재개할 수 있습니다.
```

즉 `강등`은 숨기지 않되, 복귀 경로와 보존되는 성취를 같은 화면에서 설명한다.

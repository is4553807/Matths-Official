# 데이터 저장과 보안

## 정본

MongoDB는 사용자, 플랜, 학습 진행, 평가, 주간 모의고사, 경기, 내부 MMR, 공개 경쟁전 점수, 알림, 결제와 관리자 감사 기록의 정본이다. 프로세스 메모리와 브라우저 저장소는 캐시 또는 진행 보조 용도로만 사용한다.

경쟁전 경기 정산과 주간 모의고사 내부 MMR 정산은 별도 원장과 고유 키를 사용한다. 공개 랭킹은 배치 완료 경쟁전 프로필의 공개 점수에서 직접 계산한다.

## 파일

풀이 이미지, 프로필 이미지, PDF와 자료실 파일은 `fileStorageService`를 통해 목적별 저장소에 보관한다. DB에는 공급자, 키, 크기, MIME, 해시와 보존 상태를 기록한다. 파일 접근 전에 사용자·경기·자료 권한을 확인한다.

## 웹 보안

- 세션 쿠키는 환경별 보안 속성과 공용 Mongo 세션 저장소를 사용한다.
- 앱 API는 Bearer 토큰과 역할 경계를 사용한다.
- 상태 변경 요청은 동일 출처 보호, 속도 제한과 입력 화이트리스트를 적용한다.
- CSP, HSTS, 프레임 차단, MIME 스니핑 차단과 최소 Referrer 정책을 설정한다.
- 업로드는 개수·크기·내용 시그니처를 검사한다.

## 민감정보

비밀번호는 해시만 저장한다. 게스트 생년월일은 원문 대신 비밀키 기반 다이제스트로 비교한다. 결제·Apple 거래·외부 공급자 식별자는 소유권과 재전송 검증에 필요한 범위로 보존하며 일반 사용자 응답에 노출하지 않는다.

## 삭제와 보존

계정 삭제는 연결된 개인정보와 사용자 소유 파일을 정책에 따라 제거하고, 법적·회계상 필요한 거래 기록은 접근 제한 상태로 보존한다. 임시 업로드와 만료된 증거는 스케줄러가 정리한다.

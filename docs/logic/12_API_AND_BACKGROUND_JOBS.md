# API와 백그라운드 작업

## HTTP 경계

웹 라우트는 세션 인증과 EJS 화면을 제공한다. `/api/v1`은 앱용 Bearer JSON 계약이다. 두 경계는 별도 경기 규칙을 구현하지 않고 같은 서비스 계층을 호출한다.

## Arena API

- 현재 Arena 읽기 모델과 규정 조회
- 일반전·경쟁전 상대 찾기와 상태 조회
- 친구 요청과 친선전 초대
- 경기 시작, 답안 저장, 문항 이동, 최종 제출
- 격자 풀이판 저장과 최종화
- 파일 풀이 증거, 추가 소명과 결과 조회
- 도전장 생성, 게스트 참가, 순위와 상세 기록

쓰기 명령은 `Idempotency-Key`를 사용하며 앱 경기 명령은 `X-Matths-Client-Version`도 요구한다. 동적 ID는 서비스에서 형식과 소유권을 다시 확인한다.

## 스케줄러

서버는 Mongo 연결 뒤 필요한 스케줄러를 시작한다. 경기 타이머, 증거 보존, 알림 outbox, 무결성 검토 기한, 주간 모의고사, 학원 과제, 자료 보존과 임시 파일 정리가 포함된다. 다중 프로세스에서는 Mongo 기반 lease로 한 작업만 실행한다.

## 오류와 관측

오류 미들웨어는 웹과 JSON 응답을 구분하고 내부 스택을 공개하지 않는다. 준비 상태 API는 DB와 필수 외부 설정을 확인한다. 운영 지표는 요청 시 현재 원본 DB에서 조회하며, 감사 이벤트는 사용자 비밀값 대신 코드·상태·식별 가능한 서버 ID를 기록한다.

# GOAT Arena
# Main Division Shop Policy

> 상태: **Main Division 상점 확정 정책 · v1.0**  
> 기준 시간대: `Asia/Seoul`  
> 적용 대상: **Main Division 활성 사용자 전용**

---

# 1. 목적

Main Division 상점은 사용자가 경기로 획득한 학습일수를 자발적으로 사용하도록 하면서 다음 목적을 달성한다.

- Main 사용자의 과도한 학습일수 잔액을 자연스럽게 소각
- 경기 결과를 직접 구매하지 않는 공정한 편의 기능 제공
- 학습 플랫폼에 맞는 분석·일정 관리 기능 제공
- Main 전용 소속감과 성취감 강화
- 학습일수의 희소성과 가치 유지

상점에서 사용한 학습일수는 원칙적으로 시스템에서 소각한다.

단, `방어 일정 보호권`은 예외적으로 가격 2일 중 1일을 해당 경기의 공격자에게 지연 보상으로 이전하고, 나머지 1일만 시스템에서 소각한다.

```text
일반 Main Shop 구매
→ availableLearningDays 차감
→ 상대방에게 이전되지 않음
→ SHOP_ITEM_PURCHASE_BURN 원장으로 소각

방어 일정 보호권 사용
→ 방어자 availableLearningDays -2
→ 공격자 availableLearningDays +1
→ 시스템 소각 1일 기록
```

# 2. 핵심 원칙

## 2.1 Main 전용

```text
currentCompetitiveDivision = MAIN
AND accessState = PAID_ACTIVE
→ Main Shop 이용 가능
```

Sub Division 사용자는 Main Shop을 이용할 수 없다.

## 2.2 경기 승패를 구매할 수 없음

정상적으로 승패가 판정되는 경기에서 상점 아이템은 다음 요소를 직접 변경할 수 없다.

- 문제 난이도
- 정답 판정
- 경기 점수
- 승패 결과
- Arena 랭크·순위·GP 교환
- 예치 학습일수 정산
- Skill MMR
- Final Rating
- 상대방의 정당한 승리 보상

`방어 일정 보호권`은 양측이 문제 팩을 열기 전에 경기를 승패 없이 취소하는 예외다. 이미 결과가 나온 경기를 뒤집거나 정상 승자의 보상을 바꾸는 기능이 아니다.

## 2.3 예약·경기 예치 학습일수 사용 금지

상점에서 사용할 수 있는 학습일수는 실제 사용 가능한 잔액만 해당한다.

```text
shopSpendableLearningDays
= availableLearningDays
```

다음 학습일수는 상점 구매에 사용할 수 없다.

```text
reservedLearningDays
lockedLearningDays
```

## 2.4 마지막 학습일수 보호

아이템 구매 후 최소 1일이 남아야 한다.

```text
purchaseEligible
= availableLearningDays > itemPriceDays
```

예:

```text
availableLearningDays = 3
itemPriceDays = 2
→ 구매 가능

availableLearningDays = 2
itemPriceDays = 2
→ 구매 불가
```

## 2.5 구매 즉시 정산

일반 아이템은 구매가 확정되면 가격에 해당하는 학습일수를 시스템에서 소각한다.

```text
availableLearningDays -= itemPriceDays
systemBurnedLearningDays += itemPriceDays
```

`방어 일정 보호권`은 예외적으로 가격 2일을 다음과 같이 정산한다.

```text
defender.availableLearningDays -= 2
attacker.availableLearningDays += 1
systemBurnedLearningDays += 1
```

서버 오류로 아이템 효과 또는 보상 이전이 적용되지 않은 경우에는 전체 트랜잭션을 롤백하거나 조정 거래로 복구한다.

# 4. Arena 경기 분석권

## 4.1 가격

```text
가격 = 학습일수 1일
```

## 4.2 기능

종료된 Arena 경기 한 건에 대해 상세 분석을 생성한다.

- 문항별 정답·오답 분석
- 취약 개념 분류
- 문항별 풀이 시간 분석
- 사용자의 반복 실수 유형 정리
- 생성 제한 시간 5분, 실패 시 최대 2회 재시도
- 두 번의 재시도 뒤에도 생성하지 못하면 구매를 자동 취소하고 1일을 반환
- 틀린 유형 기반 맞춤 복습 문제 10~15개
- 다음 경기 전 학습 체크리스트

## 4.3 적용 범위

```text
적용 대상 = 정산이 완료된 경기 1건
사용 시점 = 경기 종료 후
효과 = 즉시 분석 생성
```

기본 경기 결과 화면에는 필수 채점 결과와 기본 해설을 제공한다. 분석권은 기본 결과보다 상세한 진단과 맞춤 복습 콘텐츠를 제공한다.

## 4.4 제한

- 진행 중 경기에는 사용할 수 없음
- 보류 또는 무효 처리된 경기에는 사용할 수 없음
- 상대방의 개인 풀이 내용은 공개하지 않음
- 상대방과의 단순 우열 비교보다 본인 학습 진단을 중심으로 제공

# 5. 방어 휴식권

## 5.1 가격

```text
가격 = 학습일수 1일
```

## 5.2 기능

구매 시점부터 24시간 동안 일반 상향 공격의 의무 방어 후보 풀에서 제외한다.

```text
효과 시간 = 24시간
사용 제한 = 방어 편의 기능 공통 7일에 1회
중첩 사용 = 불가
```

## 5.3 적용 범위

방어 휴식권은 앞으로 서버가 선정할 일반 의무 방어 후보 풀에만 적용한다.

다음에는 적용하지 않는다.

- 이미 상대가 선정된 경기
- 이미 매치가 성립된 경기
- 이미 경기에 예치된 학습일수
- Revenge 경기
- 사용자가 자발적으로 수락한 Main 초대전
- 이미 확정된 No-show 또는 제재

## 5.4 공정성 규칙

사용자는 상대방 신원을 확인한 뒤 방어 휴식권을 사용해 해당 경기만 피할 수 없다.

```text
상대 선정 전 사용
→ 적용 가능

상대 선정 후 사용
→ 해당 경기에는 적용 불가
```

## 5.5 일요일 잠금

일요일 15:00부터 월요일 00:00까지 Arena가 잠기는 동안에는 방어 휴식권을 새로 구매할 수 없다.

기존 효과 시간이 일요일 잠금에 들어간 경우 효과 시간은 그대로 흐른다. 별도의 시간 보상은 제공하지 않는다.

# 6. 방어 일정 보호권

## 6.1 가격

```text
가격 = 학습일수 2일
```

보호권은 미리 구매해 인벤토리에 보관하지 않는다. 적용 가능한 경기 화면에서 사용하는 즉시 2일을 정산한다.

## 6.2 목적

일반 상향 공격으로 강제 배정된 방어자가 일정상 경기에 응하기 어려울 때, 상대방을 장시간 기다리게 하지 않고 해당 경기를 즉시 종료한다.

보호권을 사용하면 방어자가 경기에 응하지 않는 것으로 처리하되, No-show 패배나 제재로 처리하지 않는다.

## 6.3 적용 대상

보호권은 다음 경기에서만 사용할 수 있다.

```text
하위 티어 사용자가 상위 티어 사용자를 공격
→ 상위 티어 사용자가 의무 방어자로 배정된 일반 경기
```

다음 경기에는 사용할 수 없다.

- Revenge 경기
- 상위 티어 사용자가 생성한 하위 티어 대상 선택형 초대전
- 사용자가 자발적으로 수락한 경기
- 본인이 공격자로 생성한 경기
- 이미 No-show가 확정된 경기
- 무결성 심사 또는 운영자 보류 상태인 경기

## 6.4 사용 가능 시간

```text
보호권 사용 가능
= 경기 배정 후 3시간 이내
AND 양측 모두 문제 팩 미열람
AND 양측 모두 답안 미제출
AND 경기 무결성 검사 시작 전
```

경기 배정 후 3시간이 지나면 보호권을 사용할 수 없다.

사용 가능 시간이 일요일 전체 Arena 쓰기 잠금과 겹치면 일요일 15:00에 즉시 종료한다. 월요일 00:00에 남은 시간을 다시 열지 않는다.

상대방의 문제 풀이 상태·점수·난이도를 확인한 뒤 경기를 회피하는 용도로 사용할 수 없도록 문제 팩을 한 번이라도 열면 즉시 사용 자격을 잃는다.

## 6.5 사용 자격

공통 구매 자격과 함께 다음을 만족해야 한다.

```text
defender.availableLearningDays > 2
AND defender has no active defenseConvenienceCooldown
```

보호권 가격은 `availableLearningDays`에서만 납부한다. `reservedLearningDays`와 `lockedLearningDays`는 보호권 가격으로 사용할 수 없다.

## 6.6 학습일수 정산

보호권 사용 시 공격자가 원래 예치한 학습일수는 100% 반환한다.

```text
attacker 원래 예치 학습일수 S
→ attacker.lockedLearningDays -S
→ attacker.availableLearningDays +S
```

방어자가 원래 경기에서 예치한 대응 학습일수도 100% 반환한다.

```text
defender 원래 예치 학습일수 S
→ defender.lockedLearningDays -S
→ defender.availableLearningDays +S
```

그 후 보호권 가격 2일을 다음과 같이 정산한다.

```text
defender.availableLearningDays -2
→ attacker.availableLearningDays +1
→ 시스템 소각 1일
```

최종적으로:

```text
공격자
= 원래 예치 학습일수 100% 반환
+ 보호권 보상 1일

방어자
= 원래 대응 예치 학습일수 100% 반환
- 보호권 가격 2일

시스템
= 1일 소각
```

보호권 보상 1일은 운영자가 새로 발행하지 않고 방어자가 납부한 2일 중 1일을 이전한다.

## 6.7 경기 처리

보호권을 사용하면 경기는 즉시 다음 상태로 종료한다.

```text
matchStatus = INSURED_CANCELLED
```

처리 결과:

- Arena 랭크·순위·GP 교환 없음
- 승리·패배·공식 경기 수·Final Ranking 경기 실적 미기록
- 최근 7일 동일 상대 제외와 어뷰징 탐지 통계에는 포함
- Revenge 권한 미생성
- No-show 경고 없음
- 무결성 경고 없음
- 양측 공식 경기 슬롯 즉시 해제
- 공격자는 보상 정산 직후 새 공식 공격 가능

## 6.8 사용 제한

```text
사용 제한 = 방어 편의 기능 공통 7일에 1회
동시 여러 경기 적용 = 불가
중첩 사용 = 불가
미사용 보호권 재고 보관 = 불가
```

7일 쿨다운은 보호권 사용이 확정된 시각부터 계산한다. 방어 휴식권과 방어 일정 보호권은 같은 쿨다운을 공유하므로, 둘 중 하나를 사용하면 7일 동안 다른 하나도 사용할 수 없다.

보호권은 해당 경기 화면에서 즉시 사용하며, 미리 구매한 뒤 나중에 적용할 수 없다.

## 6.9 무료 취소와 구분

다음 사유로 경기가 불가능한 경우에는 보호권을 요구하지 않는다.

- 서버 장애
- 문제 팩 오류
- 공식 점검
- 운영자 귀책
- 광범위한 접속 장애

운영자 귀책으로 취소하는 경우:

```text
양측 예치 학습일수 100% 반환
보호권 가격 없음
자동 공격자 보상 없음
```

추가 장애 보상은 운영자가 사건별로 판단해 관리자 조정 거래로 직접 지급한다. 자동 지급 규칙에는 포함하지 않으며, 지급 사유·일수·관리자·관련 경기 ID를 감사 원장에 남긴다.

## 6.10 원자적 처리

다음 변경은 하나의 원자적 트랜잭션으로 처리한다.

```text
양측 원래 예치 학습일수 반환
+ 방어자 보호권 가격 2일 차감
+ 공격자 보상 1일 이전
+ 시스템 1일 소각
+ 경기 INSURED_CANCELLED 종료
+ 양측 공식 경기 슬롯 해제
+ 보호권 7일 쿨다운 생성
```

일부 단계만 성공하면 전체를 롤백한다.

# 7. 초대 매칭 가속권

## 7.1 가격

```text
가격 = 학습일수 1일
```

## 7.2 기능

대기 중인 Main 초대 요청 한 건의 매칭 우선순위를 높인다.

```text
효과 기간
= 구매 후 48시간
OR 실제 매치 성립 시까지
중 먼저 도달한 시점

대기열 우선순위
= 활성 가속 요청을 일반 요청보다 먼저 처리
= 활성 가속 요청끼리는 가속권 적용 시각이 빠른 순서
= 같은 시각이면 요청 생성 시각, 요청 ID 오름차순

우선순위가 올라가도 후보 사용자는 서버가 기존 적격성 필터를 거친 뒤 무작위로 선정한다. 특정 사용자를 지정하거나 최근 7일 상대 제외를 우회할 수 없다.
```

## 7.3 유지되는 조건

가속권을 사용해도 다음 조건은 변경되지 않는다.

- 공격자가 선택한 목표 티어
- 티어 차이에 따른 예치 학습일수
- 후보자의 학습일수 보유 조건
- 서버 무작위 선정
- 연관 계정 제외
- 무결성 상태 검사
- 후보자의 수락·거절 권리
- 경기 문제·채점·승패 판정

## 7.4 보장하지 않는 것

초대 매칭 가속권은 매칭 성립을 보장하지 않는다.

```text
적격 후보 없음
→ 가속권을 사용해도 매칭 불가
```

효과 기간이 끝나도 기존 초대 요청은 취소되지 않는다. 가속 효과만 종료되고 일반 대기열에서 계속 유지된다.

## 7.5 사용 제한

```text
사용자당 동시에 활성화 가능한 가속권 = 1개
한 초대 요청에 중복 사용 = 불가
```

# 8. Main 프로필 테두리

## 8.1 가격

```text
가격 = 학습일수 2일
```

## 8.2 기능

현재 시즌 동안 Main 프로필과 Arena 화면에 전용 테두리를 적용한다.

```text
효과 기간 = 현재 시즌 종료까지
경기 효과 = 없음
```

## 8.3 표시 위치

- Main Arena 프로필
- 랭킹 목록
- 경기 결과 카드
- 개인 전적 화면

## 8.4 제한

- 티어·랭크·실력 인증으로 표시하지 않음
- 구매형 장식임을 시스템상 구분
- 시즌 종료 후 자동 만료
- 환불 또는 다른 사용자 이전 불가

---

# 9. 스타일 칭호·입장 연출

## 9.1 가격

```text
가격 = 학습일수 1일
```

## 9.2 기능

사용자가 선택한 스타일 칭호 또는 경기 입장 연출을 적용한다.

예:

- Main Challenger
- Rank Breaker
- Arena Contender
- 경기 시작 전 짧은 배너
- 프로필 전적 옆 스타일 칭호

## 9.3 효과 기간

효과 기간은 현재 시즌 종료까지로 고정한다.

```text
effectEndsAt = currentSeason.endsAt
```

단, 현재 시즌 종료 10일 전부터 종료 시각 사이에 구매한 Main 프로필 테두리와 스타일 칭호·입장 연출은 다음 시즌 종료까지 이월한다. 이월은 한 번만 적용하며 그 다음 시즌으로 다시 넘기지 않는다.

## 9.4 실적 칭호와 구분

```text
실적 칭호
= 경기·학습 성과로 획득

스타일 칭호
= 상점에서 구매
```

구매형 칭호를 실력 성취 칭호처럼 표시해서는 안 된다.

# 10. 구매 자격

```text
purchaseEligible
= currentCompetitiveDivision = MAIN
AND accountStatus = ACTIVE
AND accessState = PAID_ACTIVE
AND integrityStatus = CLEAR
AND availableLearningDays > itemPriceDays
AND sundayDivisionLock = false
```

아이템별 추가 조건이 있으면 공통 구매 자격과 함께 모두 충족해야 한다.

---

# 11. 구매 처리 흐름

```text
아이템 선택
→ 현재 정책 버전·가격 조회
→ Main 활성 자격 재검증
→ availableLearningDays 재검증
→ 아이템별 사용 조건 재검증
→ 학습일수 차감
→ 효과 생성
→ 구매 원장 기록
→ 사용자 화면 갱신
```

학습일수 차감과 효과 생성을 하나의 원자적 트랜잭션으로 처리한다. 방어 일정 보호권은 양측 예치분 반환, 공격자 보상 이전, 1일 소각, 경기 종료를 모두 같은 트랜잭션에 포함한다.

```text
학습일수 차감 성공
AND 아이템 효과 생성 성공
→ 구매 확정

효과 생성 실패
→ 차감 롤백 또는 보정 거래
```

---

# 12. 원장 거래 유형

```text
SHOP_ITEM_PURCHASE_BURN
SHOP_ITEM_PURCHASE_REVERSAL
SHOP_ITEM_EFFECT_APPLIED
SHOP_ITEM_EFFECT_EXPIRED
SHOP_ITEM_EFFECT_CANCELLED
DEFENSE_SCHEDULE_PROTECTION_COMPENSATION_TRANSFER
DEFENSE_SCHEDULE_PROTECTION_BURN
DEFENSE_SCHEDULE_PROTECTION_DEPOSIT_RELEASE
```

구매 기록에는 최소 다음 정보를 저장한다.

```text
purchaseId
userId
itemId
itemPolicyVersion
priceDays
beforeAvailableDays
afterAvailableDays
purchasedAt
effectStatus
effectStartsAt
effectEndsAt
relatedMatchId
relatedInvitationId
reversalReason
```

`relatedMatchId`와 `relatedInvitationId`는 해당 아이템에 필요한 경우에만 저장한다.

# 13. 환불·복구 정책

## 13.1 사용자 단순 변심

아이템 효과가 정상적으로 적용된 뒤에는 단순 변심에 따른 학습일수 반환을 제공하지 않는다.

방어 일정 보호권은 사용 즉시 경기 종료와 공격자 보상이 확정되므로 사용 후 취소할 수 없다.

## 13.2 서버 오류

다음 조건이면 학습일수를 반환한다.

- 구매만 기록되고 효과가 생성되지 않음
- 동일 구매가 중복 차감됨
- 서버 장애로 아이템을 사용할 수 없었음
- 운영자 귀책으로 효과가 무효화됨

```text
SHOP_ITEM_PURCHASE_REVERSAL
→ 차감된 학습일수 복구
```

## 13.3 사용자가 조건을 잃은 경우

구매 후 사용자의 정지·탈퇴·Main 강등 등 사용자 상태 변화로 효과를 쓰지 못한 경우에는 원칙적으로 반환하지 않는다.

단, 매치나 초대에 종속된 아이템이 운영자 귀책으로 무효화된 경우에는 반환할 수 있다.

# 14. 판매하지 않는 아이템

## 14.1 랭크 보호권

```text
패배해도 Arena 상태 교환 없음
```

판매하지 않는다. Main의 랭크 탈취 원칙을 훼손한다.

## 14.2 학습일수 손실 방지권

```text
패배해도 예치 학습일수 반환
```

판매하지 않는다. 승리한 상대방의 정당한 보상을 없애고 예치의 의미를 약화한다.

## 14.3 상대 재선정권

```text
매칭된 상대를 확인한 뒤 다른 상대 요청
```

판매하지 않는다. 쉬운 상대가 나올 때까지 반복 선택할 수 있다.

## 14.4 공식 경기 힌트권

```text
공식 경기 중 힌트 제공
```

판매하지 않는다. 공식 경기의 승패에 직접 영향을 준다.

## 14.5 GP·티어 직접 구매

```text
학습일수 → Arena GP·티어·순위
```

판매하지 않는다. 실력 경쟁이 아니라 학습일수 소비로 랭크를 구매하게 된다.

## 14.6 랜덤 박스

```text
학습일수를 내고 무작위 보상 획득
```

판매하지 않는다. 보상의 가치가 확률에 따라 달라지고 불필요한 신뢰·법률 위험을 만든다.

# 15. 가격 정책

초기 Main Shop 가격은 다음 기준을 사용한다.

```text
1일
= 1회성 분석
= 일정 편의 기능
= 24~48시간 효과
= 가벼운 시즌 장식

2일
= 시즌 전체 장식
= 방어 일정 보호권
= 상대적으로 가치가 큰 지속 효과

3일 이상
= 초기에는 판매하지 않음
```

Main 진입 직후 학습일수가 많지 않을 수 있으므로 대부분의 아이템을 1일로 유지한다.

방어 일정 보호권 사용 후 해당 경기는 즉시 종료되고 양측의 공식 경기 슬롯을 해제한다.

Main Division 활성 사용자만 상점을 이용할 수 있다.

# 19. 확정 운영값

- 초대 매칭 가속 요청은 일반 요청보다 먼저 처리하고, 가속 요청끼리는 적용 시각 → 요청 생성 시각 → 요청 ID 순으로 처리한다.
- 스타일 칭호·입장 연출은 현재 시즌 종료까지 유지한다.
- 시즌 종료 10일 이내에 구매한 시즌 장식은 다음 시즌 종료까지 한 번 이월한다.
- Arena 경기 분석은 5분 제한, 최대 2회 재시도 뒤 실패하면 자동으로 1일을 반환한다.
- `INSURED_CANCELLED`는 공식 승패·경기 실적에서 제외하되 최근 상대 제외와 어뷰징 탐지에는 포함한다.
- 방어 휴식권과 방어 일정 보호권은 공통 7일 쿨다운을 사용한다.
- 사용자 노출 이름은 `방어 일정 보호권`으로 고정한다.
- 서버·운영자 귀책의 추가 보상은 자동화하지 않고 운영자가 감사 원장을 남겨 직접 지급한다.

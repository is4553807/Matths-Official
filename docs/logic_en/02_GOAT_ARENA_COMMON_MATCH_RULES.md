# GOAT Arena Common Match Rules

## Match unit

- A match has five questions.
- Each question has a ten-minute limit; advancing locks the answer and working.
- Desktop uses file upload, while tablet and phone use the grid board below each question.
- Capture and upload time is excluded from valid solve time.
- Voluntary forfeiture is unavailable after final submission.

## Questions and results

Normal and competitive participants may receive different question sets. The server freezes each actual prompt, answer, source accuracy rate, correctness result, solve time, and working evidence in the match snapshot. Results show both sets of five questions, submitted answers, correctness, totals, valid solve time, internal performance, and complete working. There is no separate official-answer or model-solution page.

## Outcome and settlement

Normal and competitive compare an internal performance score based on correctness, question difficulty, and valid solve time. Time is used only when the configured score difference is close. A valid final result settles once. Normal updates hidden MMR. Competitive updates internal MMR and then uses its expected win probability to calculate the public point change. Friendly and group challenges update neither MMR nor public points.

## Integrity

Competitive uses the existing automated integrity and operator-review path. Normal runs automated cheating detection without user penalties, result delay, or email; a flagged record stays out of the opponent pool until an operator approves it. Member friendly and guest challenge do not run automated cheating detection. Result and file reads require participant, challenge, or operator authorization. Arena is available every day of the week.

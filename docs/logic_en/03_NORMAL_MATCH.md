# GOAT Arena Normal Match

## Entry and difficulty

Normal is free for an authenticated student. Hidden MMR starts at 1000. There is no public normal ladder or normal tier. The server maps hidden MMR to U1–U9 difficulty and searches for a valid record close to the player's current skill.

## Opponent record selection

- The opponent is a valid completed normal record.
- Selection prefers records whose recorded hidden MMR is close to the current player.
- Exposure includes opponent questions revealed in results or working, for challengers and historical owners. Reopening an old result refreshes its window; cancelling before starting does not advance it.
- A question shown to a player is excluded from that player's next ten started normal/competitive matches. The opponent record itself can be reused with other question combinations.
- A verified baseline record is used when no real record exists in an initial range.
- The current player and historical opponent may have different five-question sets.

## Play and result

The answer and working for all five questions are required. Once submission requirements are complete, the server evaluates correctness, difficulty, and valid solve time. Automated detection never delays or penalizes the player: a clean completion enters the opponent pool immediately, while a flagged completion enters only after operator approval. No integrity email is sent. The result includes the player's submitted answers and both sides' working.

## Hidden MMR

Each win, loss, or draw recalculates only the current player's hidden rating, RD, and volatility with Glicko-2. A configurable reversal multiplier dampens a win after a losing streak or a loss after a winning streak. The historical owner's current state is not changed.

## Connections

A valid normal completion follows existing XP rules, counts toward the three-match competitive unlock, and can be shared as a group challenge from the result page.

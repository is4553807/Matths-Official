# Operator Capabilities

## Accounts and plans

Operators can search users and inspect account status, Free/Pro plan, expiry, and change history. A plan change records reason, operator, timestamp, and outcome.

## Arena operations

- Search active and completed matches
- Validate baseline problems and the question catalog
- Inspect placement profiles, internal MMR, and public competitive-point state
- Monitor 30-day one-sided MMR net/average/absolute movement and result-specific public-point changes
- Review competitive integrity signals and supplemental evidence
- Approve or invalidate flagged normal records for the opponent pool
- Authorize placement-attempt resets
- Inspect group challenges and guest records under access control

Clearing a competitive integrity review releases applicable Arena restrictions and resumes any held settlement. A normal signal never penalizes the user or delays result/XP; operator approval only returns that record to the opponent pool, and no normal-integrity email is sent.

## Learning and content

Dedicated tools manage problem banks, assessments, weekly mocks, archives, academies, community, and support. File-backed workflows expose upload validation and storage state.

## Operational metrics

The web and iPad operator surfaces query the same current source collections. They cover Free/Pro plans, Pro payments and refunds, Arena matches, record pools, placement and integrity, one-sided rating health, group challenges, and weekly mocks.

## Audit and concurrency

Money, plan, restriction, match-finalization, and user-data changes record operator identity, target, reason, and result. Idempotency keys, unique indexes, and transactions prevent duplicate application.

D = b2 − 4ac
실근의 개수를 부호 하나로 판정하기
y = x2 + c | D판별식 = b2 − 4ac
D > 0→서로 다른 실근 2개
D = 0→중근 1개
D < 0→실근 없음
그래프를 그리지 않아도 부호 하나면 된다
이차방정식의 해가 몇 개인지, 풀지 않고 알 수 있을까요?
이차함수 그래프가 x축과 만나는 점이 곧 실근입니다.
그래프를 위아래로 옮겨 보면 만나는 점의 개수가 바뀝니다.
두 개에서 한 개로, 한 개에서 없음으로.
이 셋을 가르는 값이 판별식입니다.
D = b² − 4ac
D > 0 이면 x축을 뚫고 지나가 실근이 두 개,
D = 0 이면 스치듯 닿아 중근 한 개,
D < 0 이면 x축에 닿지 못해 실근이 없습니다.
그래프를 그리지 않아도, 부호 하나로 해의 개수가 정해집니다.

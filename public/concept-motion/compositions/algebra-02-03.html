a/sin A = 2R, c² = a²+b²−2ab cos C
직각에서 코사인 항이 0 이 되어 피타고라스로 되돌아간다
삼각형의 한 변과 마주 보는 각만 알면 나머지도 구할 수 있을까요?
삼각형에 외접원을 그리고, 중심 O 를 고정합니다.
꼭짓점 하나를 원 위에서 천천히 미끄러뜨려 보겠습니다.
변 a 도, 마주 보는 각 A 도 계속 바뀝니다.
그런데 a ÷ sin A 는 소수점 아래까지 그대로입니다.
그 고정된 값이 외접원의 지름 2R 입니다.
a / sin A = b / sin B = c / sin C = 2R
이번에는 두 변을 붙잡고 사이각 C 를 벌려 봅니다.
C = 90° 일 때는 c² = a² + b².
각을 벌리면 c² 이 커지고, 좁히면 작아집니다.
그 차이를 메우는 항이 −2ab cos C 입니다.
c² = a² + b² − 2ab cos C
두 변과 사이각을 알면 코사인법칙으로 나머지 변을 구합니다.
각이 직각이면 cos 항이 0 이 되어 피타고라스 정리로 돌아갑니다.

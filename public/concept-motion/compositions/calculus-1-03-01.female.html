부정적분
F′(x) = f(x) ⇔ ∫f(x)dx = F(x) + C높이만 다른 곡선족
부정적분은 미분의 역과정
평행이동한 곡선들은 같은 기울기를 가진다
미분해서 2x 가 되는 함수는 무엇일까요?
(x²)′ = 2x
그런데 답이 하나뿐일까요?
(x² + 3)′ = 2x
상수의 도함수는 0
y = x² + C — 높이만 다른 곡선족
∫2x dx = x² + C
F′(x) = f(x) 이면 F 는 f 의 원시함수
∫f(x)dx = F(x) + C
dx 는 x 로 적분한다는 표시
C 는 적분상수
부정적분은 미분의 역과정 — 상수 하나만큼의 자유가 남는다.

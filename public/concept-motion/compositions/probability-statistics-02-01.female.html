많이 던질수록 1/6 로 좁혀 든다
쌓인 비율이 앞으로의 확률이 된다
주사위에서 1이 나올 확률이 1/6 인 걸 어떻게 알까요?
실제로 던져 봅시다. 나온 눈을 축 위에 쌓습니다.
n = 10 · 상대도수 = 0.300
1/6 과는 꽤 차이가 납니다.
n = 100 → n = 1000
던진 횟수가 늘수록 막대 높이가 고르게 맞춰집니다.
n = 1000 · 상대도수 = 0.169
1/6 = 0.1667
P(A) = A 의 경우의 수 / 전체 경우의 수
0 ≤ P(A) ≤ 1
P(S) = 1
P(∅) = 0
쌓인 비율이 좁혀 드는 그 값이 앞으로의 확률입니다.
